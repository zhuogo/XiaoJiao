# RouterGo / SelfGo · 形态与表情提案 03

更新：2026-10-31。基于用户授权，将表情与结构、配色一起设计。本轮仅更新 RouterGo 与 SelfGo；DraftGo、BenchGo 和既有配色研究保留。

## RouterGo · 专注连接

暖红身体 `#B94332`、珊瑚切角 `#F08D70`、深暖褐双眼 `#351F1B`、浅色线路 `#FFF6EE`、暖白应用图标背景 `#F6EAE3`。

专注眼在原双眼范围内收拢上缘，保持横向中心 (168,306)、各 90 宽；可见高度 104，范围 y=138–242。上缘采用柔和小圆角，下缘保留圆弧，不增加眉毛或眼白。

线路保留一处分流、两个出口，集中在身体右上方。下方出口中心 y=170，线路与端点均位于切角起点 y=190 以上。外伸长度缩短，彩色切角完整可见。

favicon 与 16–64px PNG 适当加粗线路，箭头简化为圆端点，保持分流轮廓与专注表情。

## SelfGo · 轻松整理

纸白身体 `#F1F3E7`、松绿双眼 `#265B4C`、柔绿切角 `#80A68C`、鼠尾草绿副画布 `#A8BEA3`、浅灰绿应用图标背景 `#DBE6D6`。

双眼改为圆端轻笑弧线，水平中心仍为 (168,306)，各占 90 宽，均位于原眼睛的 90 × 130 范围内。弧线不添加瞳孔、高光或嘴部。favicon 与 16–64px PNG 加粗笑眼，保持小尺寸识别。

后方保留一张副画布，相对主体向右 40、向上 42。完整组合在画布中居中，主身体位于 translate(100 211)。主身体与切角保持原几何，没有旋转或非等比拉伸。

## 两种表情版本

- `routergo-*` / `selfgo-*`：新版表情，分别为专注、轻笑。
- `routergo-neutral-*` / `selfgo-neutral-*`：相同的新结构与新配色，恢复标准双眼。只用于直接比较表情，不是旧版。
- 标准双眼尺寸为 90 × 130、R45，中心为 (168,190)、(306,190)。
- 全部版本保持身体 600 × 380、R95；切角连接 (410,380) 与 (600,190)。

## 交付文件

每种表情均包含透明背景标志、1024px 应用图标、单色、反白、favicon SVG/PNG/ICO，以及 16、32、48、64、180、192、512px PNG。SVG 为可编辑矢量。单色与反白版的双眼为透明负形。

`go-expressions-board.png` 展示两款新提案；`routergo-comparison.png` 与 `selfgo-comparison.png` 按“此前方案 / 新结构标准双眼 / 新结构表情”排列。`palette.json` 记录颜色与表情名称。

首页的表情开关同步更新当前模式的大图、单色检查、小尺寸预览和 SVG/PNG 下载。图标包包含两种表情。

旧版保存在 `logos/go/history/before-expressions/`。新提案源文件为 `scripts/go_identity_geometry.py`，导出命令：`python scripts/build_go_identities.py --brands routergo selfgo`。
