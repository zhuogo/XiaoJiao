# 首页品牌与形态案例

## 设计约束

固定小角基准身体、双眼与切角。产品之间通过配色、外围结构、前后空间关系建立差异。2026-10-31 的 RouterGo / SelfGo 表情提案未获采用，按用户最新要求恢复本轮前的原版，表情暂不变动。

几何真源为 `小角IP/geometry.json`：身体 600 × 380、R95；双眼各 90 × 130、R45，中心 (168,190) 与 (306,190)；45° 切角连接 (410,380) 与 (600,190)。本体不旋转或非等比拉伸。新增 12 款案例中的外围结构在本体之后绘制，彩色双眼、身体和切角不被覆盖。

## 首页内容

当前首页顺序：四产品动态图标群像 → 产品展台 → 12 款形态案例 → 分类资产索引。交互与布局以 [轻量单页](../06-生成器设计/轻量单页.md) 为准，不再有创建套装。

- 产品家族：DraftGo、RouterGo、SelfGo、BenchGo。保留 DraftGo 现有轨道设计与 RouterGo 原彩色方案，SelfGo 使用原版画布叠层、标准双眼与深绿应用图标底色；BenchGo 去掉两侧代码括号，保留顶部活动标签、分隔线和光标，使用小角原配色，首页默认展示，并保留全部 16 款配色研究。
- BenchGo 配色：产品展台内选择 17 套配色，同步品牌标志 / 应用图标及下载；资产索引中保留全部配色预览。
- BenchGo 双眼：16 款彩色方案采用与主色协调的深色墨眼。已替换此前的白色、奶白色眼睛；身体配色、眼睛轮廓与眼距保持不变。旧版保存在 `go/history/benchgo-light-eyes/`。
- 形态案例：12 款完整矢量设计，错落作品墙呈现。支持彩色标志、应用图标、单色检查；点击作品打开详情，在相同位置对照完整形态与同色小角基准。
- 配色系列：六款既有配色统一回标准双眼。

| 类别 | 案例 |
| --- | --- |
| 连接 | 环绕之间、双星相伴、连接有度、听见回响 |
| 收纳 | 思绪叠层、留在这一页、各有位置 |
| 陪伴 | 安心所在、轻轻靠岸、值得珍藏 |
| 探索 | 留一点白、向着微光 |

详情支持 Escape 关闭、关闭后焦点返回作品。下载 SVG / PNG 与当前完整形态或基准预览相对应，也可下载单款或完整资产包。

## 资产与维护

- 产品品牌：`frontend/public/logos/go/`；修正版：`go/v2/`。
- RouterGo / SelfGo 表情提案未采用，已整体移至 `go/history/expression-proposal-03/`，只作设计记录。当前资产、生成脚本、首页与图标包均恢复本轮前版本；恢复基准保存在 `go/history/before-expressions/`。当前不提供表情开关，后续 Logo 表情继续使用标准双眼。
- BenchGo：在 `#products` 展台选择；17 款配色完整保留，默认小角原配色。切换配色更新标志、应用图标和下载；单色版共用，单色时禁用配色选择。
- BenchGo 当前版本（2026-10-31）：身体暖米白 `#F3EBDF`、切角与活动标签砖红 `#D44A36`、深墨双眼与字标 `#222222`，与小角原色对应；展示与应用图标背景调浅为 `#E8EAE5`。光标为砖红，次级标签与分隔线为暖灰 `#B6B1A7`。保持标准几何与编辑器细节，彩色大图增加淡阴影。`go/v2/benchgo-final.zip` 为原配色图标包，`benchgo-identity.zip` 为全部配色包。正式 `benchgo-*` 图标与对应 `benchgo-original-*` 图标一致；原晴空蓝包与说明归档于 `go/history/benchgo-sky-final/`。
- BenchGo 配色真源：`scripts/go_identity_geometry.py` 中的 `BENCHGO_PALETTES`，`BENCHGO_DEFAULT_ID = 'original'` 明确指定当前默认版本，不依赖配色排列顺序。`scripts/build_go_identities.py` 导出全部资产、对比图、图标包与 `frontend/src/data/benchgo-palettes.json`。favicon 与 16–64px PNG 去除顶部细节，保留标准本体。
- BenchGo 历史：紫色方案在 `go/history/benchgo-v2/`，薄荷色加左右括号方案在 `go/history/benchgo-editor-mint/`，深色配色研究在 `go/history/benchgo-accent-palettes/`，深海蓝推荐时期的完整导出在 `go/history/benchgo-body-palettes/`，柔和配色阶段的导出在 `go/history/benchgo-soft-palettes/`。
- 新案例源文件：`scripts/build_form_studies.py`，共享基准来自 `scripts/go_identity_geometry.py`。
- 生成目录：`frontend/public/logos/studies/`；首页清单：`frontend/src/data/form-studies.json`。
- 页面：`frontend/src/main.tsx`；样式：`frontend/src/gallery.css`。
- 配色导出：`scripts/build_logo_collection.py`。
- 原 `logos/lab/` 是历史实验素材，现纳入资产索引的历史分类。

根目录执行 `python scripts/build_form_studies.py` 可重新生成全部案例、同色基准、1024px 应用图标、16/32/64/192px 小图标、单款压缩包、完整压缩包与对比图。导出需要 resvg-py 与 Pillow；展板字体使用 Windows Segoe UI。正式小角素材库不作改动。

## 验证

生产预览启动后运行 `python scripts/check_gallery.py`，检查资源完整性、旧资产 SHA256、四产品切换、案例基准与形式、下载、分类搜索、Escape / 焦点返回、减少动态偏好及移动端溢出。前端执行 `npm.cmd run typecheck` 与 `npm.cmd run build`。本轮遵照用户要求不进行视觉校验。

## 最新调整：浅背景与淡阴影

2026-10-31：本轮 RouterGo 线路与眼睛颜色、SelfGo 画布叠层与底色的修改未采用，均恢复修改前的造型与配色。仅将 BenchGo 展示与应用图标灰底由 `#C8CAC7` 调浅为 `#E8EAE5`。根据随后要求，四款产品的彩色标志与应用图标统一加淡阴影，BenchGo 17 款配色同步处理；小尺寸 16–64px、favicon、单色、反白维持平面版本。

当前四款图标均从 `go/v2/` 展示和下载。DraftGo 和 RouterGo 原始文件保留在 `go/`，导出时只对其原版图形添加阴影分组；SelfGo 原叠层和深绿应用底色不变。阴影参数由 `scripts/build_go_identities.py` 的 `add_soft_shadow` 统一维护。修改前资产及脚本归档于 `go/history/before-line-layer-lightening/`。
