# 四产品 VI 展板

## 范围

为 DraftGo、RouterGo、SelfGo、BenchGo 各制作一张独立的 2400 × 3400 px 纵向展板，共用版式与小角基准，分别使用已确认的品牌色与图标。源文件只读，不覆盖现有图标或展板。

## 每张内容

品牌定位与主标识、横向标志组合、应用图标、单色与反白、四个核心色与 HEX/RGB、字体与层级、净空和最小使用建议、实际小尺寸图标、品牌名片/启动页/产品界面应用示意。

展板品牌署语统一使用“卓越构建”，替代“小角产品家族”，不展示公司名称。

四产品定位分别为开发底座、模型连接、思考画布、全天候助手。BenchGo 使用小角原配色，而非其他研究配色。

## 规范边界

- 本体形状、双眼和切角以既有资产为准；SVG 原样嵌入并隔离内部 ID。
- 新增横向字标组合、净空、最小尺寸和字体层级为本轮 VI 使用建议，不冒充历史已定规范。
- 建议净空为完整图形可见宽度的 1/8；小尺寸直接使用既有 16/32/48/64 px 文件，不缩放复杂大标志代替。
- 反白由现有单色图形转换实色为白色，保留透明镂空；不改原文件。
- 中文使用微软雅黑，英文 Segoe UI，交付 SVG 保持文字可编辑；跨平台打开需匹配字体。PNG/PDF 固化外观。PDF 为高清栅格嵌入，不宣称印刷矢量 PDF。
- 界面与物料明确标注“应用示意”，不暗示已上线功能；不编造用户、数据或业绩。
- RGB 数字展示稿，不提供未经色彩管理校样的 CMYK/Pantone 承诺。

## 交付与入口

`frontend/public/logos/vi/` 中提供每品牌 SVG、高清 PNG、轻量预览 JPG、PDF、ZIP，以及四品牌合集 ZIP/PDF。生成脚本为 `scripts/build_vi_boards.py`。

单页资产库的“展板”分类纳入四张 VI，支持预览与 SVG / PNG / PDF 下载。当前主交付已升级为 [完整 VI 资产包](VI资产交付规范.md)：主下载及页脚指向完整资产包，旧展板 ZIP 保留为“仅下载展板文件包”。核心 API 与 MCP 不变。

## 验证

源图标哈希不变；SVG XML 合法、无 ID 冲突；PNG 尺寸正确；PDF/ZIP 完整；前端类型检查、构建、资源与下载路径验证。不做视觉验收，由用户确认。
