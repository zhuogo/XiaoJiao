# Design —— 小角 IP「拆分化」设计文档

本目录是小角 IP 拆分化体系的**设计与规范真源**：把 `小角IP/` 里的静态素材，升级为「零件 + 规则」的可组合体系，支撑围绕小角的图标 / 表情包 / 头像生成器。

## 当前产品入口

当前实现以 [轻量单页](06-生成器设计/轻量单页.md) 与 [GitHub 发布与资产分发](06-生成器设计/GitHub发布与资产分发.md) 为准：产品图标展厅、案例与资产索引。旧工作台需求文档仅记录设计演进，不再作为开发规格。所有正式及历史资产保留。

## 背景与目标

小角目前是一套优秀的静态素材（12 个表情、多种尺寸导出、VI 展板齐全），且底层条件极好：

- `小角IP/geometry.json` 已将身体、眼睛、切角**完全参数化**，标准形象可纯代码重绘；
- 12 个表情 SVG 结构统一，**表情本身就是身体之上的独立图层**，可程序化提取替换；
- `小角IP/07-规范与源文件/生成VI.py` 已验证 SVG 合成 → resvg 栅格化 → 多尺寸导出管线。

本目录要补上缺的三样东西：**拆解规范**（怎么拆）、**装饰与表情的模块库规范**（拆成什么）、**生成器规格**（怎么组合回去）。

## 阅读顺序

1. **01-IP设定** —— 先知道小角是什么、什么不能碰；
2. **02-拆解体系** —— 拆解的总框架，后续所有模块都引用它；
3. **03 / 04 / 05** —— 三类零件库，互相独立，可并行设计；
4. **06-生成器设计** —— 汇总以上内容，定义第一版产品。

## 与 `小角IP/` 素材的关系

- `小角IP/` 是**正式素材库与现有规范**，本目录**只读引用，不修改其中任何文件**；几何数据、色值、SVG 结构均以它实测为准。
- 冲突裁决：涉及现有素材的规范（几何、配色、阴影、导出尺寸）以 `小角IP/` 为准；本目录新增的规范（挂点、装饰、组合规则、生成器）是其**向上生长的扩展层**。
- 生成器所需的表情/装饰 SVG 片段，由提取脚本从 `小角IP/04-表情包/SVG/` 等现有素材**派生**，派生产物放生成器自己的资产目录，不回写素材库。
