# 挂点与坐标系统

> 本文定义小角身体上的「挂钩」：装饰往哪里挂、用什么坐标说清楚、哪些地方不能碰。

## 坐标系

采用两层坐标系，均以**设计单位**（px）计：

| 坐标系 | 原点 | 范围 | 用途 |
| --- | --- | --- | --- |
| **身体坐标系**（主） | 身体左上角 | x ∈ [0,600]，y ∈ [0,380] | 基板直绘、挂点定义、装饰片段定位（与 `prompt.md` 中眼中心 (168,190) 等表述一致） |
| **贴纸画布坐标系** | 贴纸左上角 | 780 × 560 | 表情贴纸产物；身体原点位于 (90,90) |

换算：`画布坐标 = 身体坐标 + (90, 90)`。所有挂点、装饰偏移一律用**身体坐标系**声明，渲染时统一平移。

## 挂点定义

挂点是身体坐标系中的一个锚定点 + 一条法线方向。装饰片段以**挂点为自身原点**绘制，通过元数据声明挂在哪个点上。

以下为第一版挂点集（**可讨论**：坐标为按几何推算的建议值，实现时以渲染效果微调）：

| 挂点 id | 锚点 (x,y) | 法线方向 | 适用装饰 | 说明 |
| --- | --- | --- | --- | --- |
| `head-top` | (300, 0) | ↑ 向上 | 帽子、发饰、角饰 | 头顶中点；帽子主体可伸入画布上方 90 余量区，帽檐允许略压身体上缘 |
| `eyes` | (237, 190) | — | 眼镜、墨镜、眼罩 | 双眼中点；眼镜片段内部自带左右镜片定位（对齐两眼中心 (168,190)/(306,190)，中心距 138） |
| `eye-left` | (168, 190) | — | 单眼道具（单片眼镜、眼罩） | 左眼中心 |
| `eye-right` | (306, 190) | — | 单眼道具 | 右眼中心 |
| `cheek-left` | (120, 300) | — | 腮红、贴纸、纹理 | 左脸颊 |
| `cheek-right` | (354, 300) | — | 腮红、贴纸 | 右脸颊 |
| `side-left` | (0, 190) | ← 向左 | 围巾尾、挂饰、耳机臂 | 左身侧中部 |
| `side-right` | (600, 120) | → 向右 | 挂饰 | **必须在 y < 190 区域**：y ≥ 190 的右侧是切角领地（见下） |
| `bottom` | (205, 380) | ↓ 向下 | 底部小道具、影子上附加物 | 底边中点；可用范围 x ∈ [0,410]，x > 410 即切角 |
| `floating` | 自定义 | — | 情绪小道具（爱心、汗滴、zzZ） | 不锚定身体，元数据自带画布绝对坐标，常出现在头部两侧上方 |

### 装饰片段的定位格式

装饰 SVG 片段根组携带定位声明（供生成器读取）：

```xml
<g id="deco-hat-beanie"
   data-anchor="head-top"
   data-offset="0,6"
   data-z="0"
   data-covers-eyes="false">
  <!-- 片段内部：以挂点为原点。帽子向上画，即 y 为负值 -->
  <path d="M-150 6 A150 150 0 0 1 150 6 L150 20 L-150 20 Z" fill="#D44A36"/>
</g>
```

```json
// 同一信息的机器可读形式（decorations.json 条目）
{
  "id": "deco-hat-beanie",
  "name": "毛线帽",
  "category": "hat",
  "anchor": "head-top",
  "offset": [0, 6],
  "z": 0,
  "covers_eyes": false,
  "palette_tokens": ["corner"],
  "bbox": [-150, -160, 150, 20]
}
```

- `offset`：片段原点相对挂点的微调（**可讨论**：也可以直接烘进片段坐标，二选一后写死）；
- `z`：同挂点/跨挂点的层级微调，默认 0；
- `bbox`：片段包围盒（挂点坐标系），生成器用它做碰撞与出界检查。

## 禁区与碰撞规则

### 切角保护区（绝对禁区）

切角是小角的签名（见 [小角设定总纲](../01-IP设定/小角设定总纲.md)）。保护区为身体坐标系中的多边形：

```
(410,380) → (600,380) → (600,190) → 沿 45° 斜线回 (410,380)
（右下角 R95 圆弧部分含在内）
```

**规则 D-1**：任何装饰的 `bbox` 不得与切角保护区相交。情绪小道具（floating）也不得飘入该区域。

### 眼部区（有条件开放）

眼部区为两块矩形：左眼 (123,125)–(213,255)，右眼 (261,125)–(351,255)。

- **规则 D-2**：`covers_eyes = true` 的装饰（眼镜、墨镜、眼罩类）允许覆盖眼部区，且**必须**整块覆盖双眼或声明单眼挂点，不允许只遮半只眼造成「残眼」；
- **规则 D-3**：`covers_eyes = false` 的装饰，其 bbox 不得与眼部区相交——豆豆眼是小角的表情载体，不许被帽子檐、围巾角之类的元素碰到。

### 画布与留白

- **规则 D-4**：所有产物不超出贴纸画布 780×560（身体坐标系即 x ∈ [−90,690]，y ∈ [−90,470]）；帽子等向上伸展的装饰用足上方余量，但贴纸导出时保持四周内容与边缘距离 ≥ 12（**可讨论**：贴纸需要呼吸感，90 全留白对装饰品太奢侈）；
- **规则 D-5**：装饰之间允许重叠（如帽子压住围巾上端），按 `z` 与数组顺序决定上下；同一挂点只挂一个装饰，互斥由生成器在选择器层面提示。

## safe margin 的沿用

现有规范中 90 设计单位是**独立标识**的安全留白；贴纸画布 780×560 已把四周 90 作为表情/装饰的缓冲区。生成器导出「主标识」品类时，仍按原规范执行：居中、四周 ≥ 90、无装饰（主标识 = 基板 + 表情，永不挂装饰——**可讨论**：是否允许「标识 + 帽子」这类品牌变体）。
