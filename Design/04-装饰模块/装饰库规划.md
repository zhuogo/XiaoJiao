# 装饰库规划

> 装饰层是「拆分化」价值最大的一层：表情 × 装饰 × 配色的正交组合让内容量指数级增长。本文定义装饰片段规格、组合规则与首批清单。

## 装饰片段规格

每个装饰 = 一个 SVG 片段文件 + 一条元数据。片段以**挂点为原点**、身体坐标系绘制（坐标系与挂点定义见 [挂点与坐标系统](../02-拆解体系/挂点与坐标系统.md)），根组携带 data-* 定位声明，机器可读元数据写入 `decorations.json`。

```xml
<!-- decorations/deco-glasses-round.svg -->
<g id="deco-glasses-round" data-anchor="eyes" data-covers-eyes="true">
  <!-- 镜片对齐两眼中心 (168,190)/(306,190)，中心距 138 -->
  <circle cx="168" cy="190" r="78" fill="none" stroke="#222222" stroke-width="14"/>
  <circle cx="306" cy="190" r="78" fill="none" stroke="#222222" stroke-width="14"/>
  <path d="M246 190 H228" stroke="#222222" stroke-width="14"/>  <!-- 鼻梁 -->
</g>
```

硬约束（继承 [小角设定总纲](../01-IP设定/小角设定总纲.md)）：

1. 平面纯色、无渐变无纹理；**外轮廓禁止描边**；装饰内部允许「笔画型造型细节」（罗纹缝线、镜腿、zzZ 等），使用圆端粗笔画（宽 6–18），先例 = 官方眨眼"＜"折线（v0.2 起明确）；
2. 用色必须来自色板令牌（见 [色彩规范](../05-色彩系统/色彩规范.md)），并在元数据 `palette_tokens` 中登记；
3. 阴影：装饰**不自带**阴影滤镜；若某装饰需要与身体分离的悬浮感，用纯色低透明度色块模拟（保持与基板阴影同一套参数比例），第一版建议一律不加；
4. 遵守禁区规则 D-1～D-5（切角保护区禁入、眼部区条件开放、画布出界检查）。

## 组合规则

| 规则 | 内容 |
| --- | --- |
| C-1 同挂点互斥 | 一个挂点同时只能挂一个装饰（生成器在选择器中自动置灰互斥项） |
| C-2 覆盖声明 | `covers_eyes = true` 仅限眼镜/墨镜/眼罩类；开启后表情层被其覆盖的部分不渲染问题由 z 序自然解决（装饰在表情之上） |
| C-3 跨挂点共存 | 不同挂点的装饰默认可自由组合（帽子 + 眼镜 + 围巾）；元数据可用 `conflicts: []` 声明个别互斥（如 `deco-hat-*` 与 `deco-antler-*` 都占头顶） |
| C-4 主标识例外 | 「主标识」品类永不挂装饰；装饰只出现在贴纸、头像变体、图标变体中 |
| C-5 数量上限 | 单次组合装饰数建议 ≤ 3（**可讨论**：纯工程约束，防视觉过载，可放开） |
| C-6 叠压提示 | 两件装饰 bbox 相交时警示「同挂会互相叠压」（v0.5 增补，源于爱心×蝴蝶结同色相融事故）；随机组合自动避开叠压对 |

## 设计与验收流程

1. 按本规格产出片段 SVG + 元数据；
2. 跑禁区检查脚本（D-1～D-4 自动校验 bbox）；
3. 渲染进生成器，与全部 12 表情组合过一遍目检（重点：压不压眼、出不出画布、抢不抢切角戏）；
4. 登记进本清单与 `decorations.json`。

## 目录约定（建议）

```
generator/assets/decorations/          # 片段 SVG（生成器资产目录，与素材库分离）
decorations.json                       # 元数据索引（与本文档清单同步维护）
```
