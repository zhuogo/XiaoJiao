# 小角轻量单页（当前实施规格）

## 边界

本规格替代旧工作台、项目管理与套装创建流程。保留 React / TypeScript / Vite，不增加运行时依赖。
所有现有资产、历史图标、基准、表情、装饰、配色、生成脚本、用户项目数据库均保留。删除失效的工作台页面、样式、客户端、项目 API 和相关测试；用户已修改的旧 index.html 内容完整保留，发布清理时原样归档到 archive/legacy-generator/index.html，不参与构建。

## 页面论证与内容

- 四个产品，共用一个小角：首屏四个真实产品图标组成动态展陈，可直接选择产品。
- 同一基准可以有不同性格：固定展台切换 DraftGo、RouterGo、SelfGo、BenchGo；支持品牌标志、应用图标、单色与 SVG / PNG 下载，BenchGo 保留 17 套配色。
- 延展不破坏角色：12 款案例以错落作品墙呈现，点击原生对话框查看完整形态 / 基准与下载。
- 所有资产都有归处：同页资产索引按基准、表情、装饰、配色、历史与展板分类；静态导出及完整资产包，避免将所有资产塞进首屏。

## 艺术方向

Pinned poster（seed 33381242）。小角固定的身体、双眼和切角成为展台中的不变坐标，四个产品在同一位置轮换。首屏实物图标群像，随后为可切换的大幅展台和错落案例墙。
采用原有品牌资产，页面本身以冷白、墨色为主；不同产品的淡色场景作为整块背景。保持中文系统字体，无远程字体、照片、视频或装饰性背景。图标本身即真实作品，不引入无关摄影。
简化原方向的长滚动锁定与全屏图片序列，以满足轻量单页与快速操作。使用 CSS 浮动、切换入场、IntersectionObserver 渐入；不劫持滚动、不引入动画库。提供暂停动态、reduced-motion、键盘焦点和 Escape 关闭。

## 技术与资产

页面只读取本地静态文件，不依赖 Python 后端，不请求项目或 AI 接口。保留后端核心渲染器和 compose / export / catalog / validate / random / health API，供资产维护与现有组合能力复用。
删除 /api/studio/* 接口，更新 backend/openapi.json。无 MCP 配置，无新增 MCP。
资产构建脚本派生静态表情、装饰和配色预览，并汇总正式素材及既有品牌图标；不修改源资产。数据库不进入公开下载包。

## 验收

TypeScript、生产构建、核心后端测试、静态资产完整性与 SHA256 保全检查、浏览器交互（非视觉）：产品切换、形态切换、案例基准、下载、资产过滤、Escape、移动端无横向溢出。用户明确不需要视觉校验，因此不截图、不执行视觉评分。
