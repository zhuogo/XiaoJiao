# Peeps 参考分析（公开页面只读，2026-10-26）

## 范围与证据等级

目标站点：<https://peeps.ui8.net/>。本次使用 `Invoke-WebRequest` 读取公开首页 HTML、Next.js 页面脚本和两份 CSS；没有使用站点人物素材，也没有完成浏览器点击验收。以下结论分为：**实测（HTML/CSS/脚本可直接确认）**、**源码推断（由压缩脚本逻辑推断）**、**未验证（需要真实浏览器或后端请求）**。

## 页面骨架与布局

- **实测**：Next.js 单页应用，根节点包含 Header、Scene、Message、Editor 等区域；中央 Scene 使用 `<canvas>`，页面背景色为 `#CCD7D6`。Header 有品牌标识，下载按钮在加载完成后显示。
- **实测**：桌面编辑器为白色圆角卡片，最大宽度约 944px；场景尺寸按视口高度计算（`calc(100vh - 330px)`，窄屏调整为 `calc(100vh - 440px)`），最小 272px。移动端 Scene 为 `100vw` 正方形，Editor 横向铺满并取消圆角。
- **实测**：编辑器预览项使用 flex-wrap；桌面单项约 86px，移动端按三列（`calc(33.33% - 20px)`），容器支持横向/纵向滚动。断点主要为 1419px、1023px、767px。
- **落地建议**：React 工作台采用“顶部品牌/导出入口 + 中央 SVG 预览 + 分类编辑卡片 + 底部动作栏”的结构；CSS 使用 `min-width:0`、容器滚动和 767px 断点，保证小屏上下布局。

## 分类与编辑操作

- **实测**：脚本导出 Editor 样式类名：`head`、`tab`、`previews`、`preview`、`active`，并存在 `actions`、`actionsColor`、`tabRandomize`。这说明分类 Tab、选项缩略图、当前项高亮和随机入口均为一级编辑能力。
- **源码推断**：参数对象通过键值拼接为 URL 查询串（函数 `q` 将对象值以 `-` 连接），编辑状态可被链接复现/分享。脚本中出现 `HAIR`、`Background` 等类别标识，并对头发、耳饰、眉眼、配件等图层按参数选择几何体/材质。
- **实测**：颜色选择器有独立 Picker 样式，含输入框和 alpha 控件；页面支持肤色/背景等颜色状态。
- **落地建议**：将 `expressions`、`decorations`、`palettes` 映射为可滚动分类 Tab；每个缩略图点击即更新 State 并高亮；颜色面板保留十六进制输入与透明度，避免把具体 UI8 资源复制到小角项目。

## 随机、下载、状态反馈

- **源码推断**：存在随机按钮/随机化标签（`tabRandomize`），随机函数为 `Math.floor(Math.random()*n)+1`，并在状态参数中生成组合。
- **源码推断**：下载按钮触发下载流程；下载弹窗文案明确包含两种 1000x1000 PNG：带背景与透明 Alpha；若自动下载失败，提供 “click here” 手动重试。该站点还要求登录后下载（脚本存在 `logged` 判断和 auth modal）。
- **实测**：页面包含 Loader、Message、Modal、Download 等组件样式；按钮有 hover/active 状态，过渡约 0.2–0.3s。
- **未验证**：未在真实浏览器中点击随机/下载，未验证文件内容、失败重试时序和登录流程。
- **落地建议**：小角项目按既有契约实现 `/api/random`、`/api/export?format=svg|png&size=...`；前端显示明确 loading、错误文本和可再次导出的按钮，不引入账号门槛。

## 响应式与交互细节

- **实测**：移动端 Header 下载按钮压缩为 48px 图标按钮；编辑器操作栏从卡片上方移到 `top:-64px`，分类预览改三列；模态框内边距由 40px 降为 20px，关闭按钮靠近右上角。
- **实测**：全局按钮高度约 48px、圆角 16px、带柔和阴影；字体使用 Albert Sans/Karla（另有 CircularXX）。
- **落地建议**：保持小角品牌色（暖白、墨色、砖红）替代参考站青绿色；仅借鉴信息层级、滚动与断点，不复制其 CSS、字体或人物图形。

## 对当前 React/Python 契约的对应

- `/api/catalog`：驱动分类 Tab、缩略图和默认状态。
- `/api/compose`：中央 SVG 预览；请求取消/过期结果丢弃，界面保留 loading 与错误反馈。
- `/api/validate`：导出前显示保护区、眼部、重叠等 warnings。
- `/api/random`：底部“随机”动作，返回合法 State 后重新合成。
- `/api/export`：导出 SVG/PNG；尺寸选项沿用 240/512/1024，避免参考站固定 1000px。
