# 生成器需求规格（第一版）

> 当前架构参见 [React-Python重构](React-Python重构.md)。下文单文件入口与实现状态为历史记录；IP、几何及组合规则继续有效。

> 汇总 01-05 的全部规范，定义第一版产品。目标：**尽快有一个看得见、摸得着、能导出成品的第一版**。

## 定位

**本地单页网页**（无后端、无构建链，直接打开 HTML 即用）：点选表情、挂装饰、换配色，实时预览，一键导出 SVG / PNG。

选型理由：SVG 合成与预览是浏览器原生能力，所见即所得最适合探索「表情 × 装饰 × 配色」的组合空间；批量生产等重活留给后续 CLI 阶段。

## 用户故事

1. 打开页面，看到一只标准小角（780×560 贴纸规格，透明底）；
2. 点选一个表情 → 眼睛立刻变化；
3. 点选一顶帽子 → 挂到头顶；再点眼镜 → 挂到眼部，互斥项自动置灰；
4. 切换皮肤 → 背景与装饰换色，身体恒定；
5. 点「随机」 → 抽一套合法组合；
6. 命名并导出 → 得到 `小角-开心-毛线帽.svg` 与 1024/512/240px PNG。

## 功能需求

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F1 | 实时预览画布 | 按图层拆解规范合成 SVG：scene → base → expression → decorations；基板层代码直绘（数据来自 geometry.json） |
| F2 | 表情选择器 | 列出 expressions.json 全部条目，单选必选，默认 `expr-01-standard` |
| F3 | 装饰选择器 | 按 category 分组（帽子/眼镜/…）；同挂点互斥（规则 C-1）、conflicts 声明互斥（C-3）；选中态、卸下态 |
| F4 | 配色系统 | 8 套Ⅱ级色板（体色/切角/眼睛/点缀/背景五元组，三段色带卡）+ 五路自定义取色；表情片段内容色令牌化联动（眼睛↔眨眼/墨镜/螺旋，切角↔爱心眼，点缀↔泪滴）；对比度红线自动提示；选择随本地记忆持久化 |
| F5 | 禁区校验 | 挂载时自动跑 D-1～D-5 检查；违规组合在选择器层直接禁用并提示原因 |
| F6 | 随机组合 | 从合法组合空间随机抽取（避开已知丑组合的黑名单，是否需要可讨论） |
| F7 | 导出 SVG | 当前组合序列化为独立 .svg 文件（图层 id、data-* 元数据保留，产物可反哺为素材） |
| F8 | 导出 PNG | 当前 SVG 栅格化为 1024 / 512 / 240px（浏览器 canvas 或引入 resvg wasm）；透明底 |
| F9 | 命名 | 导出文件名 = `小角-{表情名}-{装饰名列表}`，可覆盖 |

## 数据与目录架构（v0.1 实际实现）

按用户决定，生成器落在**仓库根目录**，为自包含单页（表情与几何数据由脚本注入内联，双击 `index.html` 即可用，无需服务器、无外部请求）：

```
index.html                      # 单页应用：UI + 渲染 + 禁区校验 + 导出（内联 CSS/JS 与数据）
scripts/
└── extract_expressions.py      # 表情提取 + 逐字节重合成校验 + 数据注入（--inject index.html）
```

- **表情数据**：`extract_expressions.py` 从 `小角IP/04-表情包/SVG/` 剥离基板四层、保留表情图层（ns0 前缀清洗后），注入 `index.html` 的 `<!-- DATA:EXPRESSIONS -->` 标记区；校验为「基板前缀 + 表情 + 后缀 == 源文件全文」的逐字节比对，12 个贴纸基板前缀一致性同步校验。
- **几何数据**：脚本同步注入 `小角IP/geometry.json` 全文（`<!-- DATA:GEOMETRY -->` 标记区），基板由此**参数直绘**，不落任何中间文件。
- **装饰与皮肤**：首批 8 个装饰片段、4 套Ⅰ级皮肤直接内联在 `index.html` 的 `DECORATIONS` / `SKINS` 数据区，`fill` 使用 `{{ink}}/{{corner}}/{{accent}}` 令牌，渲染时解析。
- 升级流程：素材更新后重跑 `python scripts/extract_expressions.py --inject index.html` 即可；新装饰按 [装饰库规划](../04-装饰模块/装饰库规划.md) 的片段规格加入 `DECORATIONS`。

## 渲染管线（浏览器内）

```
compose config
  → 解析 palette（令牌 → 色值）
  → 生成基板 <g id="base">（geometry.json 参数）
  → fetch 表情片段，注入 <g id="expression">
  → 按序 fetch 装饰片段，逐个做令牌替换 + 挂点平移，注入 <g id="decorations">
  → 禁区校验（bbox 与保护区/眼部区/画布求交）
  → 渲染预览；导出时 serializeToString → .svg / canvas → .png
```

## 验收口径（与素材库对齐）

导出产物对照 `小角IP/验收记录.json` 的既有标准：SVG/PNG 有效可读、透明母版、无描边、阴影参数符合 geometry.json、命名符合仓库约定。生成器自身另加：禁区校验零告警、任意合法组合渲染不抛错。

## 界面规范（v0.2，审美升级后生效）

界面语言 = VI 手册活页：白卡 + 品牌灰底座 + 展板式标题（「小角 ｜ 生成器」）。

- **色彩锁**：UI 强调色唯一 = 砖红 `#D44A36`（主按钮、选中态辅色）；表情蓝只出现在小角内容物；页面暖白 `#F7F6F2`，白卡，瓦片底品牌灰 `#C8CAC7`，预览透明底暖白 `#FAF8F4` + 可关底纹；文字深墨 `#222222`，次级 `#6F6F69`。
- **形状锁**：圆角族 = 瓦片 14 / 卡 20 / 按钮 pill，呼应身体 R95。
- **选择器**：表情与装饰一律「灰底圆角瓦片 + 真实 mini 渲染 + 底部命名」，不用文字按钮；配色为双色拼块色卡（场景色 + 点缀色）。
- **动效（纯 CSS）**：图层替换 160ms fade+scale 进入（仅变化的图层）、hover 微升、:active 下沉；`prefers-reduced-motion` 全禁。
- **文案纪律**：无版本号、无装饰 emoji、无 em-dash、数字用真实计算值（组合空间计数动态得出）；规则文字收进「组合规则」折叠。
- **快捷键**：R 随机；1–9、0 选表情。
- **D-1 判定**：切角保护区用三角×矩形精确相交（斜边 x+y=790），不做粗糙 bbox 推断，避免镜腿类长条装饰误报。
